# 👊 Fist My Bump

A fun little mini-game: tap the fist to give a fistbump.

**Live:** [https://thommsa.github.io/fist-my-bump/](https://thommsa.github.io/fist-my-bump/)

## Features

- First-person style fist emoji
- Tap / click to animate a fistbump
- Counter of total bumps given
- Count is remembered in the browser (localStorage)
- Extra sparkles every 10 bumps

## Files

- `index.html` – page structure
- `style.css` – look & animation
- `script.js` – bump logic + persistence

Pure HTML/CSS/JS — no build step, no frameworks.
